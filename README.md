# QR-kode generator

Utviklet en nettside for å generere QR-koder fra en lenke. Python/Flask-backend + JavaScript, HTML og CSS frontend + [`qrcode`](https://pypi.org/project/qrcode/)-biblioteket.

## Kjøre lokalt

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Er deployet med PythonAnywhere og siden er live på [qrstudio.pythonanywhere.com](https://qrstudio.pythonanywhere.com).
